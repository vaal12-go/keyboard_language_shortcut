# Development notes

## Icon need to be converted

Icons when used as generated by Python PIL are not supported by Lazarus giving out "Bitmap with unknown compression" error:
![Bitmap with unknown compression](/documentation/img/Bitmap%20with%20unknown%20compression.png)

To remove this error all icons need to be Batch converted using GreenFish Icon Editor:
![Batch_convert](/documentation/img/Batch_convert.png)

In Icon Editor select Batch convert, add folder with all the icons to be converted:
![add folder](/documentation/img/Batch_convert_add_folder.png)

Then in the "output" tab select output folder:
![output folder](/documentation//img/batch_convert_output_folder.png)

AND DESELECT "Skip input files with same type as output".

Then hit "OK" and "Yes" in the "Do you want to run the conversion?" dialog.

## HEAP debugging
 By default information is written to standard output, this function allows you to redirect the information to a file 
 
 ```SetHeapTraceOutput('heaptrace.log');```
  
  normally the heap dump will be written automatically at the end, but can also be written on demand any time
